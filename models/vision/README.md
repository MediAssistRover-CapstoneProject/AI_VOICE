# Vision model assets

These assets were copied from the local MAR_Fall_AI working tree, including
its existing YOLOv8n-pose ONNX/PT and optional MediaPipe task files.

They are pretrained pose models, not models retrained for the robot's low camera.
Default runtime: `yolov8n-pose.onnx`; no model download or training is needed to
start local inspection. Keep models separate from Python source and runtime logs.

YOLO/Ultralytics and MediaPipe assets retain their upstream licenses; this
integration does not change their licensing. Training data is not included.
